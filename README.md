# 세일즈 대화록을 메일 세일즈 액션플랜으로

## 제출 요약

세일즈 미팅 대화록, 상담 기록, 통화 녹취 텍스트, 강연 메모를 받아 한국어 회의록과 메일 세일즈 실무에 바로 반영할 수 있는 액션플랜으로 정리하도록 돕습니다.

이 Skill은 단순 회의록 작성이 아니라, 대화 속에서 다음 미팅에 물어봐야 할 질문, 상대에게 필요한 것, 우리가 줄 수 있는 것, 제안 및 후속 액션을 구조화합니다. 특히 세일즈 담당자가 미팅 후 팔로업 메일, 제안서 초안, 리드 nurturing, outbound 메시지 개선에 활용할 수 있도록 설계했습니다.

제출물은 실제 고객 데이터가 아니라 익명 처리된 대화록 또는 공개 가능한 데모 텍스트를 기준으로 사용합니다. 실제 고객명, 연락처, 이메일, 계약 조건, 내부 전략, 비밀값은 공개 저장소에 포함하지 않습니다.

## 해결하려는 문제

세일즈 담당자는 미팅이나 상담이 끝난 뒤 대화 내용을 빠르게 정리해야 합니다. 하지만 실제 업무에서는 미팅 노트 작성, 고객 니즈 파악, 후속 질문 정리, 팔로업 메일 방향 설정이 매번 반복되고 시간이 많이 듭니다.

특히 메일 세일즈 실무에서는 단순히 “좋은 메일 문구”를 쓰는 것보다, 고객이 어떤 맥락에 있고 무엇을 필요로 하며 우리가 어떤 가치를 줄 수 있는지를 정리하는 것이 중요합니다.

이 Skill은 다음 흐름을 재사용 가능한 절차로 정리합니다.

1. 세일즈 대화록 또는 메모를 입력합니다.
2. 개인정보와 민감정보 포함 여부를 확인합니다.
3. 우리가 추가로 물어봐야 할 질문을 추출합니다.
4. 상대에게 필요한 것과 우리가 줄 수 있는 것을 구분합니다.
5. 제안 및 액션플랜을 정리합니다.
6. 메일 세일즈 실무에 활용할 수 있는 후속 방향을 만듭니다.

## 대상 사용자

- 세일즈 미팅 후 회의록을 빠르게 정리해야 하는 AE, SDR, BDR
- 고객 상담 내용을 기반으로 팔로업 메일을 작성해야 하는 담당자
- 통화 녹취나 미팅 메모를 세일즈 액션으로 바꾸고 싶은 사용자
- Skillathon에서 반복 가능한 업무 절차를 Codex Skill로 정리하려는 참가자
- 실제 고객 데이터 없이 익명화된 샘플로 세일즈 workflow를 검증하려는 사용자

## 입력

이 Skill은 다음 입력을 받을 수 있습니다.

- 세일즈 미팅 대화록
- 상담 기록
- 통화 녹취 텍스트
- 강연 또는 세미나 메모
- 고객 인터뷰 기록
- 회의 대상, 고객사 이름, 참석자, 회의 날짜
- 목표: 팔로업 메일 작성, 제안서 준비, 다음 미팅 질문 정리, outbound 메시지 개선, 세일즈 액션플랜 생성

공개 제출용 데모에서는 실제 고객 데이터가 아니라 익명 처리된 대화록 또는 mock data만 사용합니다.

## 출력

대표 출력물은 다음과 같습니다.

- 한국어 세일즈 회의록
- 우리의 질문 리스트
- 상대에게 필요한 것
- 우리가 줄 수 있는 것
- 제안 및 액션플랜
- 메모
- 메일 세일즈 실무에 반영할 수 있는 후속 방향
- 민감정보 확인 및 마스킹 기준
